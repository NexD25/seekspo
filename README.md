# SeekSpo

An AI-powered local discovery and decision platform for Manipur's local businesses,
with code-mixed (Manipuri-English) sentiment analysis and comparative business ranking.

MCA 3rd semester dissertation project.

## Stack
- Backend: FastAPI (Python)
- Database: PostgreSQL
- Frontend: React + Tailwind
- Intelligent layer: Groq API (weak supervision) + fine-tuned XLM-RoBERTa/IndicBERT
